# Horror-Prototype

A first-person story horror prototype set indoors.

Built January 2021 with Unity and C#.

This is a learning project from before I worked professionally as a games
programmer. I have kept it public on purpose. The older repositories on this
account trace the route from here to shipping large-scale simulation systems in
Unreal Engine, and that route is worth showing.

Current work: [github.com/mln-grg](https://github.com/mln-grg)
